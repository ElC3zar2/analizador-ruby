\# Analizador Ruby



Proyecto de Autómatas y Lenguajes Formales.



El proyecto consiste en desarrollar en Java un analizador para un subconjunto

del lenguaje Ruby.



\## Análisis



El sistema contemplará:



\- Análisis léxico

\- Análisis sintáctico

\- Análisis semántico

\- Símbolos

\- Alfabeto

\- Palabras o lexemas

\- Tokens



\## Tecnologías



\- Java 11

\- Apache NetBeans 11.3

\- Maven

\- Git / GitHub



\## Herramientas previstas



\- JFlex para análisis léxico

\- Analizador sintáctico por definir

\- Java para análisis semántico



\## Lenguaje analizado



Ruby



\## Integrantes



\- Frontend / Líder

\- Backend

\- Documentación / QA
